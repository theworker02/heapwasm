# heapwasm

Heap identifiers and wasm tokens for idempotent workflows.

**Site:** https://theworker02.github.io/heapwasm/

## Install / run

```bash
git clone https://github.com/theworker02/heapwasm.git
cd heapwasm
node src/cli.js
node --test
```
